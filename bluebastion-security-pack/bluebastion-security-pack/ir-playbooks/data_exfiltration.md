# IR Playbook: Potential Data Exfiltration

**Goal:** Confirm/deny exfil and mitigate.

## Actions
1. Define suspected source/destination and time window.
2. Query network/proxy and endpoint telemetry for large transfers.
3. Quarantine accounts/devices; block egress if needed.
4. Engage legal/PR if breach suspected.
5. Add DLP controls and user awareness follow-up.
